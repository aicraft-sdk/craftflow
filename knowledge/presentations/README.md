# Presentations

Marp slide decks. Sources live in `sources/{slug}/slides.md`; built HTML lands in `export/{slug}.html`.

Build a deck:

```bash
cd knowledge/presentations
npx @marp-team/marp-cli sources/{slug}/slides.md -o export/{slug}.html
```
